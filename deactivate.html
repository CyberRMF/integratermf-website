License Management

Activate a new license or deactivate an existing one

Application

Activate License

Enter your license key on a new machine or activate an air-gapped system

Deactivate License

Release your license from the current machine to transfer it to another device

Online Activation
Air-Gapped Activation
1

Open CyberRMF Integrate or Admin Tools

Launch the application on the machine you want to activate. You will be prompted to enter your license key on first launch.

2

Enter your license key

Paste the license key for that app from your purchase email. Each app has its own key. The application will contact the license server to validate and bind the key to your machine.

3

Activation complete

Once validated, the application unlocks and your license is bound to this device. You can begin creating workspaces immediately.

Troubleshooting: If activation fails, ensure the machine has internet access and that the license key has not already been activated on another device. To transfer, deactivate the old machine first. For assistance, contact info@cyberrmf.com.
On an air-gapped machine, open the application. It will display a short activation code unique to that machine. Write this code down.
No USB drives or file transfers required. Keep your air-gapped environment secure. The response code is cryptographically signed to your specific machine, license key and app.

Why only by email? We send the response code only to the email address on the license, never to this page. Someone who knows your license key and email still cannot get a response code. The email says which activation code it was made for, so you can spot a request you didn't make.
Online Deactivation
Air-Gapped Deactivation
Heads up - this releases every machine currently activated on this license key. All of the key's machine slots are freed, and every one of those installs will require re-activation.

To release only one specific machine, open CyberRMF Integrate or Admin Tools on that machine and use License Management → Deactivate License → Online → Deactivate This Machine, or use the Air-Gapped Deactivation tab with a code generated by that machine.
1

Enter your license key and email

Provide the license key and the email used at purchase. We check that the email matches the license.

2

Enter the code we email you

We email a confirmation code to the address on the license. Enter it on this page to release all machines currently attached to this license. The code works for 10 minutes.

3

Re-activate wherever you need

Once deactivated, your license key is freed and can be activated on any machine. Open Integrate or Admin Tools and enter your key.

No email? Check your spam folder. The code works for 10 minutes. If you ask for a new code, only the newest one works.

Why an emailed code? It shows that the request comes from the license owner. Someone who only knows your license key and email cannot release your machines.

Whenever a machine is released, here or in the app, we email a notice to the address on the license.
On the air-gapped machine, open the application and go to License Management → Deactivate License → Air-Gapped → Generate Deactivation Code. It will display a short deactivation code unique to that machine. Write this code down.
No USB drives or file transfers required. Keep your air-gapped environment secure. Only the machine itself can produce its deactivation code.

When the machine is released, we email a notice to the address on the license.
