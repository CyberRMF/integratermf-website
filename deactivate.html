License Management

Activate a new license or deactivate an existing one

Activate License

Enter your license key on a new machine or activate an air-gapped system

Deactivate License

Release your license from the current machine to transfer it to another device

Online Activation
Air-Gapped Activation
1

Open CyberRMF Integrate or Admin Tools

Launch the application on the machine you want to activate. You will be prompted to enter your license key on first launch.

2

Enter your license key

Paste the license key from your purchase confirmation email. The application will contact the license server to validate and bind the key to your machine.

3

Activation complete

Once validated, the application unlocks and your license is bound to this device. You can begin creating workspaces immediately.

Troubleshooting: If activation fails, ensure the machine has internet access and that the license key has not already been activated on another device. To transfer, deactivate the old machine first. For assistance, contact info@cyberrmf.com.
1

Generate an activation code

On the air-gapped machine, open the application. It will display a short activation code derived from the machine’s hardware fingerprint. Write this code down.

2

Enter the code on this page

On any internet-connected machine (or phone), navigate to this page and enter your activation code, license key, and email below.

3

Enter the response code on the air-gapped machine

After submission, you will receive a response code. Return to the air-gapped machine and enter this response code in the application to complete activation.

Your Response Code — write this down

Enter this code in the application on the air-gapped machine to complete activation.

No USB drives or file transfers required. Keep your air-gapped environment secure. The response code is cryptographically signed to your specific machine.
Online Deactivation
Air-Gapped Deactivation
1

Enter your license key and email

Provide the license key and the email used at purchase. We’ll verify ownership and release the machine activation.

2

Receive a new activation

Once deactivated, your license key is freed and can be activated on your new machine. Open Integrate or Admin Tools and enter your key.

1

Generate a deactivation code

In the application, navigate to the deactivation option. The app will display a short deactivation code. Write this code down.

2

Enter the code on this page

On any internet-connected machine, navigate to this page and enter your deactivation code and email below.

3

License released

Once verified, the deactivation processes server-side. Your license key is now freed and can be activated on a new machine using the activation workflow above.

No USB drives or file transfers required. Keep your air-gapped environment secure. The deactivation code is cryptographically signed by your machine, proving you control the license.
