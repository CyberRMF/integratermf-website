4. SOFTWARE DESCRIPTION

4.1 CyberRMF Integrate provides the following core capabilities:

    (a) Artifact management — interactive Security Control Traceability Matrix
        (SCTM), Plan of Action and Milestones (POA&M), Continuous Monitoring
        (CONMON), policy and procedure documents, and related compliance
        artifacts.

    (b) Inventory tracking — asset inventory with NIST SP 800-53 control
        requirement mapping, native drag-and-drop floorplan layouts, and
        end-of-life tracking.

    (c) Third-party integration — optional outbound connections to SIEM, antivirus
        / endpoint detection and response (EDR), and vulnerability management
        platforms configured by the Licensee.

    (d) STIG validation — import and parsing of XCCDF benchmark files for
        Security Technical Implementation Guide compliance checks.

    (e) Auditing — network diagnostics (ping, traceroute, DNS lookup) and
        cyber hygiene health dashboards.

    (f) Workspace export and import — full workspace packaging as ZIP archives
        for transfer between users, organizations, or Security Control
        Assessors (SCAs).

4.2 CyberRMF Admin Tools provides the following capabilities:

    (a) Ports, Protocols, and Services (PPS) generation — enumerates running
        processes and active network connections on target hosts.

    (b) Installed software inventory — collects software lists from Windows
        (WMI/CIM) and Linux (package manager queries) systems.

    (c) Encryption verification — checks BitLocker status (Windows) and block
        device encryption (Linux) on target hosts.

    (d) Log collection — enumerates and exports Windows event logs and Linux
        system logs from remote systems.

    (e) Active Directory user enumeration — queries AD for user accounts using
        PowerShell or LDAP.

    (f) DNS spot check — performs local nslookup operations to verify hostname
        and IP consistency against inventory records.

    (g) Domain join verification — queries Active Directory for domain-joined
        computer objects.

4.3 Admin Tools writes scan results to the shared Workspace directory. Integrate
reads these results to populate dashboards, reports, and artifact views. The two
applications communicate exclusively through the shared file system and do not
use inter-process communication, network sockets, or any external relay.


5. ADMIN TOOLS — CREDENTIALS AND ELEVATED PRIVILEGES

5.2 Credential Handling. Credentials entered into Admin Tools are stored

third party, and are automatically cleared after ten (10) minutes of application
inactivity or upon explicit user action. During active scan operations,
credentials may be passed to child processes (PowerShell, SSH) via environment

8. NETWORK OPERATIONS

8.1 Integrate Network Activity. Integrate performs local network diagnostic
operations including ICMP ping, traceroute, and DNS lookups (nslookup) for
auditing and cyber hygiene assessment purposes.

8.2 Admin Tools Network Activity. Admin Tools performs targeted remote operations
against hosts listed in the Licensee's inventory. These operations include WMI
queries (TCP port 135 and dynamic RPC ports), WinRM sessions (TCP ports
5985/5986), and SSH connections (TCP port 22). Admin Tools does NOT perform
subnet sweeps, port scanning of arbitrary hosts, or network discovery beyond the
hosts explicitly listed in the inventory.

8.3 Log Collection. Admin Tools can copy Windows event log files (.evtx) and
Linux system logs from remote hosts to a local directory selected by the
Licensee. The Licensee is responsible for securing collected log data in
accordance with organizational policies.
